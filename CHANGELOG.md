# Changelog

All notable changes to Bomalo Tunnel will be documented in this file.

## [0.1.0] - 2026-09-01

### Added
- Initial release of Bomalo Tunnel
- Multi-transport support (TCP, QUIC, WebRTC, WireGuard, KCP)
- AI-powered adaptive transport selection
- eBPF kernel acceleration for Linux
- Edge Mesh networking with auto-failover
- Adaptive DPI evasion (traffic mimicry, jitter injection)
- Bilingual CLI (English/Persian) with interactive menu
- Mandatory pre-installation server tests (DNS, ping, TCP)
- Auto-detection of public IP
- SSL certificate auto-setup with Certbot
- WebSocket real-time dashboard
- gRPC + REST APIs
- systemd and Docker deployment
- One-line install script
- Animated SVG banner for GitHub

### Security
- Noise Protocol encryption (ChaCha20-Poly1305)
- Argon2id key derivation
- SHA-256 verified releases
